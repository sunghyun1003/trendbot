# 트렌드 아카이브(trendbot) 구축 계획 v2: "꼭 알아야 할 것만"

## 0. 배경과 목표

**왜 만드나:** 이전 계획은 하루 2~3천 건을 모아 전부 AI로 분류하는 방식이었고, 반려되었습니다. 이 아카이브는 **올라온 것을 전부 읽는다는 전제**로 씁니다. 그래서 "전 국민, 혹은 트렌드에 민감한 사람이라면 무조건 알아야 하는 것"만 남겨야 합니다.

**성공 기준:**
- 매일 아침 7:30에 **20~30개 항목**이 올라오고, 10~15분이면 다 읽습니다.
- 그중 팀이 '유지'로 누르는 비율이 80% 이상입니다.
- 그날의 진짜 큰 이야기를 놓치는 일은 주 2건 이하입니다.

**확정된 전제**

| 항목 | 결정 |
|---|---|
| 사용 범위 | 팀 내부 전용 |
| 비용 | 무료 우선, 유료는 항목별로 선택 도입 |
| 하루 분량 | 20~30개 |
| 구성 | 전국구 필수 카드 + 채널별 1위 한 줄씩 |
| AI 편집자 | Claude Opus 5.5 |

**핵심 원칙 3가지**
1. **수집은 넓게, 화면은 좁게.** 각 커뮤니티 베스트 목록을 훑은 수백 건은 '온도계'로만 씁니다. 사람도 AI도 이걸 읽지 않습니다.
2. **'필수' 판정은 읽을 수 있는 규칙이 합니다.** 이유가 항상 카드에 적혀 있습니다(예: "남초 2곳 + 여초 2곳 + 구글 트렌드 5만+").
3. **AI(Opus 5.5)는 최종 후보 약 30건에만 붙습니다.** 편집자 역할로 요약, 맥락, 태그를 쓰고, 이상한 것을 빼는 일을 합니다.

## 1. '꼭 알아야 할 것'의 정의: 확산 게이트

**아이디어:** 전 국민이 아는 이야기는 '어디에나 있는' 이야기입니다. 그래서 **독자층이 서로 다른 커뮤니티들이 각자의 베스트 목록에 같은 이야기를 동시에 올렸는지**를 핵심 기준으로 씁니다. 대부분의 플랫폼이 공유 수를 공개하지 않기 때문에, 이 '확산'이 공유 수를 대신합니다.

### 1-1. 독자층 묶음(포드)

| 포드 | 독자층(통념, 운영하며 보정) | 소스(베스트 목록만) |
|---|---|---|
| P1 | 남 10~20대 | 디시 실시간 베스트, 웃긴대학 베스트, (에펨 포텐: 차단 없을 때만) |
| P2 | 남 20~30대 취미 | 루리웹 베스트, 디젤매니아 인기글 |
| P3 | 남 30~50대 | 뽐뿌 HOT·핫딜, 클리앙 추천, 보배드림 베스트 |
| P4 | 여 10~20대 | 인스티즈 이슈/인기 |
| P5 | 여 20~30대 | 더쿠 HOT |
| P6 | 여 30~50대 | 네이트판 톡커들의 선택(일간), 82쿡 |
| P7 | 영상 | 유튜브(검색 발견, 채널 평소 대비 이상치) |
| P8 | SNS | 인스타 감시 계정 이상치, X 트렌드 키워드 |
| S | 검색·뉴스 | 구글 트렌드 KR RSS, 네이버 언론사별 많이 본 뉴스(또는 구글 뉴스 KR) |

같은 포드 안의 사이트 4곳에 올라와도 1로 셉니다. 남초 사이트끼리만 퍼진 것은 '전국구'가 아니기 때문입니다.

### 1-2. 등급 (하나라도 해당하면 '필수' 후보)

| 등급 | 조건(초기값, 보정 기간에 조정) | 배지 |
|---|---|---|
| **A 전국구** | 커뮤니티 포드 3개 이상 **+ 남녀 교차**, 또는 포드 4개 이상 + S | 전국구 |
| **B 급부상** | 커뮤니티 포드 2개 + (S 또는 유튜브·SNS 반향), 또는 강한 S + 포드 1개 | 급부상 |
| **M 단일채널 폭발** | 대형 게시판에서 역대급 반응(상위 0.5%), 또는 유튜브 채널 평소의 10배 이상 + 24시간 100만 회 이상 (쇼츠는 별도 기준) | 단일채널 폭발 |
| **E 선행** | 한 채널에서만 크게 터졌지만 곧 번질 것 (상위 1%, 또는 평소 대비 5배). AI 편집자가 본문 맥락을 보고 "1주 안에 비회원도 접하게 될까?"를 판단 | 선행 |

**제외**
- 일상 수치: 날씨, 로또, 환율, 정상 종료된 경기 결과
- 커뮤니티 내부 싸움, 팬덤 전용, 광고·바이럴, 개인 신상, 중복

### 1-3. 날마다 분량을 정하는 규칙
- 첫 보정 기간이 끝나면 **기준을 고정**합니다. 그래서 그날 건수 자체가 "오늘 얼마나 바빴나"를 보여 줍니다.
- 조용한 날에 빈자리를 채우지 않습니다. 대신 '조용한 날' 배너를 붙입니다.
- **큰 사건은 하나로 묶습니다(우산 카드).** 체포·입장문·밈·반응이 각각 카드가 되지 않고, 카드 1장 + 하위 줄 ≤3로 정리됩니다.
- **필수 카드는 모든 등급을 합쳐 최대 15장**입니다. 정치는 2장 이하, 사회/사건은 3장 이하입니다. 넘친 것은 '그 외' 한 줄(≤3)로 보여 줍니다.
- **어제 본 이야기는 다시 나오지 않습니다.** 다만 발행 이후 새 포드 2곳 이상에 번졌거나, 새 검색·뉴스 이벤트나 새 전개(사과, 소송, 품절 등)가 있으면 '업데이트'로 한 번 더 나옵니다.

- **하루 분량:** 필수 카드 8~15 + 채널 1위 약 12줄 + 부가 줄 ≤6 = **약 20~30개**
- **채널 1위:** 채널마다 종합 반응 1위 한 줄입니다. 강도를 함께 표시합니다: 평소 수준 / 강함(상위 30%) / 역대급(상위 5%). 이미 카드에 들어간 글이면 '↗ 카드 #n'만 표시합니다. 조회·댓글·좋아요별 1위는 아카이브의 채널 페이지에서 따로 봅니다.
- **맥락이 없으면 꾸며내지 않습니다.** AI가 근거를 못 찾은 항목은 원제목을 그대로 두고 '맥락 확인 필요' 꼬리표를 붙입니다.

## 3. 선별 흐름

| 단계 | 하루 양 | 방법 | AI |
|---|---|---|---|
| ① 온도계 수집 | 게시판 약 12곳 × 상위 20행 × 하루 5회 → 고유 글 약 500건 (제목·링크·수치만) | 목록 페이지만 읽고, 본문과 닉네임은 저장하지 않음. 수집 시각 01:30·06:30·12:00·17:00·22:00 | ✕ |

| ⑤ 맥락 확보 | 후보마다 대표 글 1~2개 | 본문 앞 600자를 **메모리에서만** 읽고 버림 + 구글 뉴스 스니펫 + 유튜브 설명 | ✕ |
| ⑥ AI 편집 | 약 30건 + 단독 밈 후보 약 60개(제목만) | Opus 5.5: 같은 밈 묶기, 헤드라인, 왜 알아야 하나, 태그, E등급 판단, 제외 표시 | ○ |

**AI 편집자 규칙 (`config/editor_rules.md`, 한국어, 깃허브 웹에서 직접 수정)**
- 판단 기준은 "트렌드에 민감한 한국 마케터가 내일 이걸 모르면 민망한가?"입니다.
- 제공된 맥락에 없는 고유명사는 쓰지 않습니다.
- A등급은 빼지 못하고 '주의' 꼬리표만 붙일 수 있습니다. 광고·중복·개인 신상만 제외할 수 있습니다.
- 뺀 것은 화면에 접힌 채로 남고, 원클릭으로 되살릴 수 있습니다.

**광고·바이럴 걸러내기**
- 감시 채널에는 유형(크리에이터/브랜드/레이블/미디어)을 붙입니다. 브랜드·레이블 채널은 좋아요·댓글 비율이 평소 이상일 때만 M·E 등급을 받습니다. 광고로 산 조회수는 반응 비율이 낮기 때문입니다.
- 서로 다른 포드에 90분 안에 동시에 올라왔고, 제목이 비슷하고, 브랜드명이 들어 있으면 '동시다발 의심' 꼬리표를 붙입니다. 이 경우 검색 신호나 댓글 반응이 따로 확인되어야 통과합니다.

## 5. 반응 지표와 정렬

- **저장하는 지표:** 사이트가 보여 주는 그대로입니다(조회, 추천/좋아요, 댓글). **공유 수는 거의 모든 플랫폼이 비공개**라서 '확산'(몇 개 포드·사이트로 번졌나)으로 대신합니다.
- **채널끼리 비교할 때:** 원래 숫자가 아니라 **그 채널 안에서 몇 등인지(백분위)** 로 비교합니다. 첫 30일은 데이터가 적어 순위(채널 상위 3위)와 고정 하한을 쓰고, 30일이 지나면 백분위로 바꿉니다. 평일과 주말 기준도 따로 둡니다.
- **매일 화면:** 정렬 기능이 없습니다. 등급 → 점수 순서로 정리되어 나옵니다.
- **아카이브 정렬:** 필수점수, 확산, 반응 백분위, 속도(급상승), 논쟁(조회당 댓글), 공감(조회당 추천), 첫 등장 시각, 지속 일수. 조회순·댓글순·좋아요순(원래 숫자)은 **채널 하나를 골랐을 때만** 켜집니다.

## 6. 분류 (최종 20~30개에만 적용)

- **분야:** 연예/방송 · 음악 · 스포츠 · 게임 · IT · 패션/뷰티 · 음식 · 쇼핑/딜 · 경제 · 사회/사건 · 정치 · 생활/육아 · 자동차 · 여행
- **속성:** 밈 · 챌린지 · 이슈/사건 · 논란 · 제품/딜 · 음악 · 장소 · 인물 · 캐릭터/IP · 정보 · 콘텐츠 · 광고/캠페인
- **연령·성별:** 어느 포드에서 퍼졌는지를 기준으로 추정합니다(예: P4+P5 → 10~30대 여성, 남녀·세대 교차 → 전 연령). v3에서 데이터랩으로 보정합니다. 화면에는 근거 꼬리표(확산 기반 추정 / 데이터 / AI 추정)를 붙입니다.
- **마케터 플래그:** 활용 기회 / 브랜드 주의

## 7. 기술 구성 (모두 무료, AI만 유료)

| 역할 | 도구 | 비고 |
|---|---|---|
| 한국 사이트 수집 | 상시 켜 둔 PC를 GitHub 'self-hosted runner'(깃허브가 시킨 작업을 내 PC가 대신 실행)로 연결 | 목록만 가져와 DB에 저장. 회사 IP를 쓸지는 IT 확인 필요. 대안: 집 미니PC 또는 국내 VM(월 $5~10) |
| 판정·AI·사이트 생성 | GitHub Actions(정해진 시각에 코드를 자동 실행하는 무료 서비스) | 수집이 끝나면 다음 단계가 이어서 실행됨(시계 기준 연쇄 X). 무료 분량 경고는 1,500분 |
| 데이터 저장 | Supabase 무료(500MB) | 온도계 데이터 14~60일 뒤 정리. 외부 접근 차단(RLS) |
| AI 편집 | Claude Opus 5.5 | 동기 호출, JSON 출력, 거부 시 대체 처리. 실패하면 'AI 없이' 등급 통과분만 원제목으로 발행 |
| 사이트 | Astro 정적 사이트 → Cloudflare Pages | 수집 후 매번 새로 생성 |
| 로그인 | Cloudflare Access(무료 50명) | **pages.dev 주소와 미리보기 주소까지 막혔는지** 자동 점검 |
| 피드백 저장 | Pages Function(로그인 토큰 검증) → Supabase | 키는 서버에만 둠 |
| 상태 페이지 | 소스별 정상/고장, 한국어 조치 안내, AI 잔액 | 비개발자도 고칠 수 있게 |

## 8. 법·운영 원칙 (내부용)

- 저장하는 것은 제목, 링크, 수치, AI 요약뿐입니다. 본문은 AI가 읽을 때 메모리에서만 쓰고 버립니다. 닉네임은 저장하지 않습니다.
- robots.txt(수집 허용 범위를 적은 파일)를 지킵니다. 사이트당 목록 요청은 하루 5회, 글 페이지는 하루 3개 이하입니다. 자동 로그인과 차단 우회는 하지 않습니다.
- 사내 열람 전용입니다. 검색엔진 노출을 막고(noindex), 저장소는 비공개로 둡니다.
- 유튜브 수치는 정책상 30일마다 새로 받거나 지웁니다.
- 근거: 야놀자 v. 여기어때 사건에서 크롤링은 형사상 무죄였지만, 민사(부정경쟁방지법)에서는 10억 원 배상 책임이 인정됐습니다. 그래서 최소 수집 원칙을 지킵니다.

## 9. 단계별 로드맵 ([할 일] → 기대 결과)

**Phase 0: 확인 (1주, 수집용 PC에서 실행)**
- [ ] 게시판별로 로그인 없이 보이는지, robots.txt, 지표 표시 여부, 차단 여부 확인 → **포드별 소스 표** (빈 포드가 있으면 기준을 먼저 수정)
- [ ] 게시판 자체 일간 베스트 페이지가 있는지, 밤 시간 1쪽에 글이 머무는 시간 → 수집 시각 확정
- [ ] 디젤매니아 공개 범위 → 자동 수집 또는 수집 버튼 결정
- [ ] 구글 트렌드 RSS, 언론사 랭킹, 유튜브 검색 품질 3일 점검 → S 기준값 초안
- [ ] 3일치 데이터로 묶기 품질 점검(밈 20쌍 포함, 병합 정확도 90% 이상) → 별칭 사전 초안
- [ ] 회사 IP 사용·보관 범위 IT/법무 확인 → 내부 정책 확정

**v1: 핵심 (2~3주)**
- [ ] 게시판 약 10곳(6개 포드 모두 포함) + 구글 트렌드 + 언론사 랭킹 + 유튜브 검색 발견 → 하루 5회 온도계 적재
- [ ] A/B/M 등급, 우산 묶기, 상한, 어제 중복 제거 → 필수 카드 생성
- [ ] Opus 5.5 편집(맥락 확보 + 헤드라인 + 태그 + 제외 표시) → 카드 문장 완성
- [ ] 아침 화면 + 채널 1위 줄 + 피드백 버튼 + 로그인 + 상태 페이지 → 팀원이 7:30에 열람
- [ ] 보정 모드: 7일차부터 '베타' 표시로 공개하고, 하루 상위 15개만 Y/N 평가. 5일 연속 안정되면 정식 전환 → 기준 고정

**v2: 넓히기 (v1에서 2주 동안 유지율 80% 이상일 때)**
- [ ] 유튜브 감시 채널 50개(쇼츠·롱폼 분리), 인스타 감시 계정 30개 → M·E와 SNS 신호
- [ ] E(선행) 등급, 업데이트 카드, 주간 리포트(놓친 것이 어느 단계에서 빠졌는지) → 튜닝 근거
- [ ] 넷플릭스·박스오피스·앱스토어 신호, 썸네일 기반 밈 묶기, 디젤매니아 연결 → 커버리지 확대

**v3: 선택**
- [ ] 데이터랩 연령 보정, 쓰레드·틱톡(놓친 것 분석 결과에 따라), 유료 옵션

감시 리스트는 Claude가 초안을 만들고 마케팅팀이 승인합니다. 이후에는 "이 채널 추가할까요?" 제안으로만 늘어납니다.

## 13. 검증 방법

| 항목 | 목표 | 측정 |
|---|---|---|
| 정밀도 | 카드 '유지' 비율 ≥80% | 피드백 버튼 14일치 |
| 재현율 | 놓친 것 ≤2건/주 | '놓친 것' 입력 + **외부 기준 비교**: 주 1회 평소 읽는 트렌드 뉴스레터(예: 캐릿) 항목을 붙여 넣어 자동 대조 |
| 신선도 | '이미 앎' ≤30% | 피드백 버튼 |
| 선행 적중률 | M·E 카드의 70% 이상이 7일 안에 다른 포드로 번짐 | 자동 |
| 분량 | 하루 중앙값 20~30개 | 자동 |
| 중복 | 같은 데이터로 이틀 연속 돌렸을 때 반복 0건 | 자동 테스트 |
| 수집기 | 사이트별 저장 HTML로 파싱 테스트 통과 | 자동 테스트 |
| 보안 | 로그인 없이 접속하면 모든 주소가 차단됨(302/403) | 자동 점검 |
| AI 요약 | '맥락 확인 필요' 외 요약 오류율 ≤5% | 보정 기간 수동 검수 |
