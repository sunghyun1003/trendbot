# 시작 안내서: 명령어 없이 3단계

ㄷㅅㅂㄱ는 이렇게 나눠 돌아갑니다. 사용자가 하는 일은 웹 화면에서 누르는 것뿐입니다.

| 누가 | 하는 일 | 사용자가 할 일 |
|---|---|---|
| GitHub 서버 (무료) | 커뮤니티 9곳, 구글 트렌드·뉴스, 다음 연예 랭킹, X 실시간 트렌드, 유튜브(급상승·인기 차트) 수집, AI 편집, 사이트 만들기·올리기 | 없음 (자동) |
| Cloudflare (무료) | 사이트 보여 주기, 팀원 로그인 잠금, 피드백 저장, 정시 실행기(06:30 발행·2시간마다 수집 시작) | 없음 (자동) |

집 PC나 설치 프로그램은 필요 없습니다.

**걸리는 시간:** 처음 한 번 약 40분(대부분 키 발급). 이후에는 할 일이 없습니다.

---

## 1단계. 키 넣기 (30분)

[키 발급 안내서](keys-guide.md)대로 키를 발급받아 GitHub '비밀값' 화면에 넣습니다.

## 2단계. '처음 설정' 버튼 한 번 (5분, 기다리기만)

1. https://github.com/sunghyun1003/trendbot/actions/workflows/setup.yml 을 엽니다.
2. 오른쪽의 **Run workflow → Run workflow**(초록 버튼)를 누릅니다.
3. 5분쯤 뒤 새로고침하면 실행 기록 옆에 ✓가 생깁니다. 기록을 누르면 **사이트 주소**가 적혀 있습니다(예: `https://dsbg.pages.dev`).

이 버튼이 자동으로 하는 일:
- Cloudflare에 사이트, 피드백 저장소, 팀원 로그인 잠금을 만듭니다.
- 이어서 첫 수집과 첫 발행까지 진행합니다.

✗가 뜨면 기록을 눌러 보세요. 맨 위 요약에 무엇을 고치면 되는지 한국어로 적혀 있습니다(대부분 키 이름 오타나 토큰 권한 부족). 고친 뒤 다시 누르면 됩니다. 몇 번을 눌러도 안전합니다.

## 3단계. 사이트 열고 즐겨찾기 (1분)

1. 사이트 주소로 들어가 이메일을 입력하고, 메일로 온 6자리 번호로 로그인합니다.
2. 회사 PC와 휴대폰 브라우저에 즐겨찾기해 둡니다.
3. 아래 **상태** 탭에서 수집 상태, 키 ✓/✗, 실행 버튼을 확인할 수 있습니다.

---

## 4단계 (선택). 내 도메인 연결

[키 발급 안내서 8번](keys-guide.md)대로 Hostinger 도메인을 Cloudflare에 등록하고 `SITE_DOMAIN`을 넣은 뒤 '처음 설정'을 한 번 더 누릅니다.

## 5단계 (선택, 나중에). 인스타 감시 계정

[키 발급 안내서 9번](keys-guide.md)대로 Meta 키를 넣고, 상태 탭에서 감시할 계정을 적습니다.

## 이후: 자동 운영 (한국 시각)

| 시각 | 하는 일 |
|---|---|
| 2시간마다 (매시 7분) | 커뮤니티·검색·뉴스·X·유튜브 수집 |
| 06:30 | 수집 → 피드백 반영 → 오늘의 판 → 사이트 올리기 (07:00 전후 완료) |

- 정시 실행기가 멈추면 GitHub 자체 예약이 대신 돕니다(늦을 수 있음). 같은 날 두 번 발행되지는 않습니다.
- 급하면 **상태** 탭의 **지금 발행**을 누르세요.

## 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| 상태 탭에 키 ✗ | ✗ 옆 '넣기'로 다시 넣은 뒤, '처음 설정' 한 번 더 |
| 아침 판이 07:30 넘어 올라옴 | '처음 설정' 기록에서 '정시 실행기' 줄 확인 → ✗면 keys-guide 3번 '권한 추가' |
| 한 사이트만 계속 고장 | Claude Code에 "고장 수리: (사이트 이름)" |
| 오늘 판이 안 올라옴 | 상태 탭 '최근 실행'에서 빨간 줄을 눌러 확인 → 그 화면을 Claude Code에 보여 주기 |
