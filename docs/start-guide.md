# 시작 안내서: 명령어 없이 4단계

ㄷㅅㅂㄱ는 이렇게 나눠 돌아갑니다. 사용자가 하는 일은 웹 화면에서 누르는 것뿐입니다.

| 누가 | 하는 일 | 사용자가 할 일 |
|---|---|---|
| GitHub 서버 (무료) | 커뮤니티 9곳·검색·뉴스·유튜브 수집, AI 편집, 사이트 만들기·올리기 | 없음 (자동) |
| Cloudflare (무료) | 사이트 보여 주기, 팀원 로그인 잠금, 피드백 저장 | 없음 (자동) |
| 집 PC 도우미 | 디젤매니아(네이버 카페)만 수집 | 처음 한 번 더블클릭, 네이버 직접 로그인 |

**걸리는 시간:** 처음 한 번 약 40분(대부분 키 발급). 이후에는 할 일이 없습니다.

---

## 1단계. 키 넣기 (30분)

[키 발급 안내서](keys-guide.md)대로 키를 발급받아 GitHub '비밀값' 화면에 넣습니다.

## 2단계. '처음 설정' 버튼 한 번 (5분, 기다리기만)

1. https://github.com/sunghyun1003/trendbot/actions/workflows/setup.yml 을 엽니다.
2. 오른쪽의 **Run workflow → Run workflow**(초록 버튼)를 누릅니다.
3. 5분쯤 뒤 새로고침하면 실행 기록 옆에 ✓가 생깁니다. 기록을 누르면 **사이트 주소**가 적혀 있습니다(예: `https://trendbot.pages.dev`).

이 버튼이 자동으로 하는 일:
- Cloudflare에 사이트, 피드백 저장소, 팀원 로그인 잠금을 만듭니다.
- 이어서 첫 수집과 첫 발행까지 진행합니다.

✗가 뜨면 기록을 눌러 보세요. 맨 위 요약에 무엇을 고치면 되는지 한국어로 적혀 있습니다(대부분 키 이름 오타나 토큰 권한 부족). 고친 뒤 다시 누르면 됩니다. 몇 번을 눌러도 안전합니다.

## 3단계. 사이트 열고 즐겨찾기 (1분)

1. 사이트 주소로 들어가 이메일을 입력하고, 메일로 온 6자리 번호로 로그인합니다.
2. 회사 PC와 휴대폰 브라우저에 즐겨찾기해 둡니다.
3. 아래 **상태** 탭에서 수집 상태, 키 ✓/✗, 실행 버튼을 확인할 수 있습니다.

## 4단계. 집 PC 도우미 (디젤매니아용, 5분)

1. 집 PC에서 사이트에 로그인 → **상태** 탭 → **도우미 설치 파일 받기**를 누릅니다.
2. 받은 `dsbg-setup.cmd`를 더블클릭합니다.
   - 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
   - 검은 창에 1~7단계가 차례로 진행됩니다(3~5분). 창을 닫지 말고 기다립니다.
3. 마지막에 Edge 창이 열리면 네이버에 **직접** 로그인합니다('로그인 상태 유지' 체크).
4. 로그인한 Edge 창을 닫으면 끝입니다. 바로 첫 디젤매니아 수집이 진행됩니다.

알아 둘 것
- 집 PC는 **켜 두고 윈도우 로그인 상태**로 두면 됩니다. 화면 잠금은 괜찮습니다.
- 도우미는 30분마다 조용히 '살아 있음'을 알리고, 하루 2번 디젤매니아를 수집합니다. 새 버전도 스스로 받습니다.
- 네이버 로그인이 풀리면 사이트 **상태** 탭에 빨간 표시가 뜹니다. 그때 집 PC 바탕화면의 **ㄷㅅㅂㄱ 네이버 로그인** 아이콘을 눌러 다시 로그인하세요.
- 평소 쓰는 주 계정 대신 **수집 전용 네이버 계정** 사용을 권장합니다.
- 도우미를 지우려면: 작업 스케줄러에서 `dsbg-helper` 삭제, `%LOCALAPPDATA%\dsbg` 폴더와 바탕화면 아이콘 삭제.

## 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| 상태 탭에 키 ✗ | ✗ 옆 '넣기'로 다시 넣은 뒤, '처음 설정' 한 번 더 |
| 상태 탭 '집 PC 연결 끊김' | 집 PC가 꺼졌거나 윈도우에서 로그아웃됨 → 켜고 로그인 |
| '네이버 다시 로그인 필요' | 집 PC 바탕화면 **ㄷㅅㅂㄱ 네이버 로그인** |
| 한 사이트만 계속 고장 | Claude Code에 "고장 수리: (사이트 이름)" |
| 오늘 판이 안 올라옴 | 상태 탭 '최근 실행'에서 빨간 줄을 눌러 확인 → 그 화면을 Claude Code에 보여 주기 |
